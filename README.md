# Capstone Project

## Self-Hosted RAG Chatbot

A Retrieval-Augmented Generation (RAG) chatbot capable of answering questions from uploaded PDF documents using a locally hosted Large Language Model.

### Features

- PDF Upload
- Text Extraction
- Text Chunking
- Vector Embeddings
- FAISS Vector Search
- Local LLM Integration
- Context-Aware Responses
- Source Citations

### Tech Stack

- Python
- Streamlit
- Ollama
- Qwen 3
- Sentence Transformers
- FAISS
- PyMuPDF
